## 1. فلسفة النسخة الأولية وتجربة الاستخدام المتكاملة (End-to-End User Journey)

تتضمن النسخة الأولية (MVP) **رحلة مستخدم متكاملة (End-to-End User Experience)** تبدأ من إنشاء القناة وحتى تصدير فيديو فعلي مكتمل بالصوت والمونتاج والميتا-داتا وفحص التراخيص القانونية، مدعومة بـ **واجهة استخدام محلية أولية (Minimal Local GUI)** تتصل بنواة المعالجة الصامتة (Headless CLI Core) عبر طبقة خدمات مفصولة (Decoupled Service Layer).

```
                      رحلة المستخدم المتكاملة في النسخة الأولية (MVP)
                      ──────────────────────────────────────────────
                      
  [1. اختيار/إنشاء القناة] ──> [2. معالج المشروع والفكرة] ──> [3. اختيار القالب والأبعاد]
  (Channel Dashboard)          (Idea Input Wizard)            (9:16, 1:1, أو 16:9)
                                                                       │
                                                                       ▼
  [6. التصدير وحزمة النشر] <── [5. المعاينة بمشغل الفيديو] <── [4. مراجعة المشاهد والأصول]
  (Strict License Gate)        (Preview Player)               (T2V / I2V / Ingest Media)
```

## 2. مصفوفة توزيع الميزات (Feature Allocation Matrix: In-Scope vs. Out-of-Scope)

| الوحدة الوظيفية | المتضمن في النسخة الأولية (In-Scope MVP) | المؤجل للإصدارات اللاحقة (Post-MVP) |
| :--- | :--- | :--- |
| **واجهة الاستخدام** | **واجهة استخدام محلية خفيفة (Minimal Local GUI):** إدارة القنوات، معالج المشاريع، شاشة مراجعة المشاهد، مراقب الطوابير، ومشغل المعاينة والتصدير. | واجهة سحابية متقدمة متعددة المستخدمين (Enterprise Multi-user Web App). |
| **محرك النواة** | **Headless CLI Core:** تشغيل كافة العمليات البرمجية بشكل صامت وقابل للاستدعاء من الواجهة عبر طبقة الخدمات. | واجهات REST API خارجية عامة موجهة للمطورين الخارجيين. |
| **طرق التوليد** | **تعددية المسارات المعتمدة:** دعم مسار **Text-to-Video**، ومسار **Image-to-Video**، ومسار **استيراد الوسائط الجاهزة (Direct Media Ingest)**. | **مسار Video-to-Video (V2V):** مؤجل لإصدار لاحق، مع تصميم طبقة التكامل المعيارية لتسهيل إضافته لاحقاً دون تعديل النواة. |
| **نسب العرض للأبعاد** | **3 أبعاد رئيسية:** 9:16 (Shorts)، 1:1 (Shorts المربع وخلاصات التواصل)، و 16:9 (أفقي وتجميعات بتمويه الخلفية). | التوسيع التوليدي للكانفاس (Generative Outpainting 4K). |
| **إدارة القنوات** | عزل منطقي منظم لكل قناة (مجلدات مستقلة، ملفات تعريف، وسجلات تراخيص معزولة). | عزل مادي على خوادم وقواعد بيانات سحابية منفصلة. |
| **الأصول والتراخيص** | مستودع وسائط منظم + سجل تتبع التراخيص والسند القانوني (`licenses.json`) + سجل تدقيق (`license_audit.log`). **السماح بالاستيراد والمعاينة وحظر التصدير حتى حسم الحقوق**. | فحص بصري آلي لحقوق النشر عبر مطابقة قواعد بيانات عالمية بالذكاء الاصطناعي. |
| **وحدة الشخصيات** | وحدة تخصصية اختيارية لحفظ مراجع الشخصية وتمريرها لمولدات الصور. | فحص آلي دقيق للاتساق بنماذج الرؤية قبل معايرتها تجريبياً في المرحلة 4. |
| **الصوت والمونتاج** | رندر FFmpeg، ميكساج الصوت بمانع تشويه حاسم (True Peak Limiter بقيمة -1.0 dBTP مرجعية)، وقيم جهارة وخفض موسيقى قابلة للتهيئة. | تحرير صوتي متعدد المسارات يدوي بواسطة Timeline مرئي معقد. |
| **إدارة الطوابير** | طابور محلي بـ SQLite يدعم وضع WAL، استئناف المهام تلقائياً، وتتبع التكلفة، ومراقبة مؤشرات الضغط للترقية. | شبكة عمال معالجة موزعة عبر عدة سيرفرات بـ Redis و Celery. |
| **الميتا-داتا والامتثال** | توليد العنوان والغلاف والوصف ووسم الذكاء الاصطناعي وتصنيف COPPA وفق القواعد الرسمية. | النشر المباشر الآلي المجدول على حسابات YouTube و TikTok عبر الـ APIs. |

## 3. معايير القبول لإطلاق النسخة الأولية (MVP Acceptance Criteria)

تعتبر النسخة الأولية مكتملة وناجحة وقابلة للاعتماد عند تحقق الشروط التالية:
1. **تجربة استخدام متكاملة عبر الواجهة (GUI Complete Walkthrough):**
   * قيام المستخدم بفتح الواجهة المحلية، واختيار القناة، وإدخال فكرة جديدة، وتوليد السيناريو، ومعاينة كليبات المشاهد واستبدال كليب أو استيراد وسيط محلي، ثم مراجعة الصوت وتشغيل الفيديو النهائي في مشغل المعاينة، وتصديره بنجاح دون كتابة أمر طرفي واحد.
2. **إنتاج حلقة تجريبية ناجحة لقناة DreamMatter:**
   * إنتاج فيديو شورتس متكامل الأركان (9:16) لشخصية كرتونية بمواقف كوميدية، مع حلقة دائرية سلسة، وتصدير حزمة الميتا-داتا والتراخيص الخاصة به.
3. **التحقق من العزل المنطقي:**
   * التأكد من أن مشروعاً تم إنشاؤه في قناة DreamMatter لا تظهر أصوله أو مشاريعه داخل قناة وثائقية أخرى عند التبديل بينهما في الواجهة.
4. **تحمل الأعطال والاستئناف:**
   * قطع الاتصال بالإنترنت عمداً أثناء توليد أحد المشاهد، والتحقق من أن النظام يعيد المحاولة ويستأنف العمل من نفس المشهد دون إعادة توليد الأصول المنجزة مسبقاً.
5. **تتبع التكلفة وبوابة التراخيص الصارمة:**
   * ظهور تقرير مالي دقيق بتكلفة الـ APIs المستهلكة لكل مشروع، وحظر تصدير أي فيديو يحتوي على وسائط مجهولة الترخيص ما لم يتم حسم السند القانوني أو تسجيل استثناء صريح في الـ Audit Log.
